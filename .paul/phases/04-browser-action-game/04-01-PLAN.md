<acceptance_criteria>

## AC-1: Canvas renders
```gherkin
Given a user is authenticated and navigates to /game/EGLL
When the page loads
Then a Phaser canvas fills the viewport with a scrolling star background and a player rectangle visible at bottom center
```

## AC-2: Player movement and firing
```gherkin
Given the game canvas is active
When the user presses WASD or arrow keys
Then the player moves in that direction, clamped to canvas bounds; pressing Space fires player bullets upward; auto-fire activates at a slower rate when Space is not held
```

## AC-3: Enemy system
```gherkin
Given the game is running
When frames pass
Then enemies spawn at the top and drift down; each enemy fires bullets downward; enemies exit the bottom and are removed; difficulty (speed + spawn rate) ramps up over the 75-second level
```

## AC-4: Collision and damage
```gherkin
Given enemies and bullets are active
When an enemy bullet hits the player
Then battery decreases by HIT_DAMAGE (50); when an enemy body collides with the player, battery decreases by HIT_DAMAGE × 2 (100); player bullets that hit enemies remove both
```

## AC-5: Win/lose conditions
```gherkin
Given the game is running
When 75 seconds elapse with battery > 0
Then onComplete({victory: true, battery: current}) is called; if battery hits 0 first, onComplete({victory: false, battery: 0}) is called instead
```

## AC-6: HUD accuracy
```gherkin
Given the game is running
When battery changes or time passes
Then the left bar reflects current battery (green → yellow → red), the right bar shows time remaining (blue → orange), the center bar shows km remaining with a label
```

        Timer bar: bg rect at x=GAME_WIDTH-185, fill rect
        KM bar: bg rect between battery and timer, fill rect + text label

      Init arrays: enemies=[], playerBullets=[], enemyBullets=[]

    update(time, delta):
      if (this.gameOver) return

      // Delta normalization — convert ms delta to frame ticks at target FPS
      const dt = delta / (1000 / FPS)

      // Progress and difficulty ramp (matches Python logic exactly)
      const durationFrames = LEVEL_DURATION * FPS
      const progress = this.frame / durationFrames
      const scale = 1.0 + (this.difficulty - 1) * 0.25 + (this.level - 1) * 0.08
      const baseEnemySpeed = ENEMY_BASE_SPEED * (0.8 + scale * 0.4)
      const baseSpawnInterval = Math.max(10, Math.floor(ENEMY_BASE_SPAWN_INTERVAL / scale))
      const ramp = 1.0 + progress * 0.6
      const enemySpeed = baseEnemySpeed * ramp
      const spawnInterval = Math.max(8, Math.floor(baseSpawnInterval / ramp))
      const fireInterval = Math.max(12, Math.floor(Math.max(15, Math.floor(ENEMY_BASE_FIRE_INTERVAL / scale)) / ramp))

      // Player movement
      const left = this.cursors.left.isDown || this.wasdKeys.A.isDown
      const right = this.cursors.right.isDown || this.wasdKeys.D.isDown
      const up = this.cursors.up.isDown || this.wasdKeys.W.isDown
      const down = this.cursors.down.isDown || this.wasdKeys.S.isDown
      if (left) this.player.x -= PLAYER_SPEED * dt
      if (right) this.player.x += PLAYER_SPEED * dt
      if (up) this.player.y -= PLAYER_SPEED * dt
      if (down) this.player.y += PLAYER_SPEED * dt
      this.player.x = Phaser.Math.Clamp(this.player.x, 48, GAME_WIDTH - 48)
      this.player.y = Phaser.Math.Clamp(this.player.y, 48, GAME_HEIGHT - 48)

      // Player firing
      this.fireCooldown = Math.max(0, this.fireCooldown - dt)
      const wantFire = this.spaceKey.isDown || (this.frame % (PLAYER_FIRE_INTERVAL * 3) === 0)
      if (this.fireCooldown <= 0 && wantFire) {
        const b = this.add.image(this.player.x, this.player.y - 48, 'bullet_player')
        b.setData('dy', -BULLET_SPEED)
        this.playerBullets.push(b)
        this.fireCooldown = PLAYER_FIRE_INTERVAL
      }

      // Enemy spawning
      this.spawnTimer += dt
      if (this.spawnTimer >= spawnInterval) {
        this.spawnTimer = 0
        const ex = Phaser.Math.Between(20, GAME_WIDTH - 20)
        const variant = Phaser.Math.Between(0, 2)
        const e = this.add.image(ex, -42, `enemy${variant}`)
        e.setData('speed', enemySpeed + Phaser.Math.FloatBetween(-0.5, 0.5))
        e.setData('drift', Phaser.Math.FloatBetween(-1.5, 1.5))
        e.setData('fireTimer', Phaser.Math.Between(0, fireInterval))
        e.setData('fireInterval', fireInterval)
        this.enemies.push(e)
      }

      // Update enemies + enemy firing
      const remainingEnemies: Phaser.GameObjects.Image[] = []
      for (const e of this.enemies) {
        e.y += e.getData('speed') * dt
        e.x += e.getData('drift') * dt
        if (e.x < 0 || e.x > GAME_WIDTH) e.setData('drift', -e.getData('drift'))
        const ft = e.getData('fireTimer') - dt
        e.setData('fireTimer', ft)
        if (ft <= 0) {
          const b = this.add.image(e.x, e.y + 42, 'bullet_enemy')
          b.setData('dy', ENEMY_BULLET_SPEED)
          this.enemyBullets.push(b)
          e.setData('fireTimer', fireInterval + Phaser.Math.Between(-10, 10))
        }
        if (e.y < GAME_HEIGHT + 20) remainingEnemies.push(e)
        else e.destroy()
      }
      this.enemies = remainingEnemies

      // Update bullets
      for (const b of this.playerBullets) b.y += b.getData('dy') * dt
      for (const b of this.enemyBullets) b.y += b.getData('dy') * dt
      this.playerBullets = this.playerBullets.filter(b => { if (b.y < -10) { b.destroy(); return false; } return true; })
      this.enemyBullets = this.enemyBullets.filter(b => { if (b.y > GAME_HEIGHT + 10) { b.destroy(); return false; } return true; })

      // Collision: player bullets vs enemies
      const playerR = new Phaser.Geom.Rectangle(this.player.x - 40, this.player.y - 40, 80, 80)
      const hitEnemyIdxs = new Set<number>()
      const hitBulletIdxs = new Set<number>()
      for (let ei = 0; ei < this.enemies.length; ei++) {
        const e = this.enemies[ei]
        const er = new Phaser.Geom.Rectangle(e.x - 42, e.y - 42, 84, 84)
        for (let bi = 0; bi < this.playerBullets.length; bi++) {
          const b = this.playerBullets[bi]
          const br = new Phaser.Geom.Rectangle(b.x - 3, b.y - 6, 6, 12)
          if (Phaser.Geom.Intersects.RectangleToRectangle(er, br)) {
            hitEnemyIdxs.add(ei)
            hitBulletIdxs.add(bi)
          }
        }
      }
      this.enemies = this.enemies.filter((e, i) => { if (hitEnemyIdxs.has(i)) { e.destroy(); return false; } return true; })
      this.playerBullets = this.playerBullets.filter((b, i) => { if (hitBulletIdxs.has(i)) { b.destroy(); return false; } return true; })

      // Collision: enemy bullets vs player
      for (const b of this.enemyBullets) {
        const br = new Phaser.Geom.Rectangle(b.x - 3, b.y - 5, 6, 10)
        if (Phaser.Geom.Intersects.RectangleToRectangle(playerR, br)) {
          this.currentBattery -= HIT_DAMAGE
          b.destroy()
          this.enemyBullets = this.enemyBullets.filter(x => x !== b)
          if (this.currentBattery <= 0) { this.triggerLose(); return; }
        }
      }

      // Collision: enemy bodies vs player
      for (const e of this.enemies) {
        const er = new Phaser.Geom.Rectangle(e.x - 42, e.y - 42, 84, 84)
        if (Phaser.Geom.Intersects.RectangleToRectangle(playerR, er)) {
          this.currentBattery -= HIT_DAMAGE * 2
          e.destroy()
          this.enemies = this.enemies.filter(x => x !== e)
          if (this.currentBattery <= 0) { this.triggerLose(); return; }
        }
      }

      // Passive drain: 33% of MAX_BATTERY over LEVEL_DURATION
      const passiveDrainPerFrame = 0.33 * MAX_BATTERY / (LEVEL_DURATION * FPS)
      this.currentBattery = Math.max(0, this.currentBattery - passiveDrainPerFrame * dt)

      // Scroll background
      if (this.bgTile) this.bgTile.tilePositionY -= 1 * dt

      // HUD update
      this.updateHUD(progress)

      // Frame counter + win check
      this.frame += dt
      const timeLeft = Math.max(0, (durationFrames - this.frame) / FPS)
      if (this.frame >= durationFrames) { this.triggerWin(); return; }

    updateHUD(progress):
      const batRatio = Math.max(0, this.currentBattery / MAX_BATTERY)
      const durationFrames = LEVEL_DURATION * FPS
      const timeRatio = Math.max(0, 1 - this.frame / durationFrames)
      const kmRatio = timeRatio  // km tracks time remaining
      const BAR_W = 175

      // Battery fill width + color
      this.batteryBarFill.width = BAR_W * batRatio
      const batColor = batRatio > 0.4 ? 0x00c850 : (batRatio > 0.15 ? 0xffb400 : 0xdc2828)
      this.batteryBarFill.fillColor = batColor

      // Timer fill
      this.timerBarFill.width = BAR_W * timeRatio
      this.timerBarFill.fillColor = timeRatio > 0.3 ? 0x50a0ff : 0xff7800

      // KM bar + text
      this.kmBarFill.width = (GAME_WIDTH - 2 * (10 + BAR_W + 8)) * kmRatio
      const kmLeft = Math.round(450 * kmRatio)
      this.kmText.setText(`${kmLeft} KM`)

    triggerWin():
      this.gameOver = true
      const onComplete = this.registry.get('onComplete') as (r: {victory: boolean; battery: number}) => void
      onComplete({ victory: true, battery: Math.round(this.currentBattery) })

    triggerLose():
      this.gameOver = true
      const onComplete = this.registry.get('onComplete') as (r: {victory: boolean; battery: number}) => void
      onComplete({ victory: false, battery: 0 })

    Avoid: Phaser Arcade physics bodies (not needed — manual rect intersection is simpler for this game)
    Avoid: mutating arrays while iterating — collect indices first, then filter
  </action>
