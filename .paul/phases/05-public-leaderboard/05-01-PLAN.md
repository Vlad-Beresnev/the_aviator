  <action>
    Replace the stub with a full "use client" component:

    - `useState` for `scores: Score[]`, `loading: boolean`, `error: string | null`
    - `fetchScores` async function: calls `api.getScores()`, sets scores or error
    - `useEffect`: call `fetchScores()` on mount; set up `setInterval(fetchScores, 60000)`;
      return cleanup that calls `clearInterval`
    - Refresh button: calls `fetchScores()` on click
    - Table columns: Rank | Player | Money | Awareness | Last Active
      - Rank: row index + 1
      - Player: `score.name`
      - Money: `score.money.toLocaleString()` prefixed with `$`
      - Awareness: `score.global_awareness`
      - Last Active: `new Date(score.created_at).toLocaleDateString()`
    - Loading state: show "Loading..." text while fetching
    - Error state: show error message if fetch fails
    - Styling: Tailwind only, no new packages — keep it minimal for MVP
      (a basic table with some padding, a header row, a refresh button)

    Do NOT send an auth header manually — `api.getScores()` uses `apiFetch` which
    conditionally includes the token only if present, and GET /scores ignores it anyway.
